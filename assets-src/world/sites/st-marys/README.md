# St Mary's Cathedral authored project

`st-marys.blend` is the canonical, independently editable Blender source for the
Cathedral of Saint Mary of the Assumption (1971, Belluschi / Nervi / McSweeney,
Ryan & Lee) at Geary & Gough on Cathedral Hill. Its `SITE_st_marys` collection
is linked into the human-facing San Francisco master composition and exported
separately as `/regions/st-marys.glb` for proximity streaming in the WebGPU
world.

The project uses real-world scale and placement:

- 255 ft (77.7 m) square podium with glass curtain walls behind travertine
  piers, a red-brick plaza platform, and the Geary-side entry stair.
- 190 ft cupola — eight hyperbolic-paraboloid shell segments sweeping from a
  square base to a Greek cross at the summit, generated as explicit outer
  travertine and inner Nervi-coffer surfaces (the export pipeline does not
  apply modifiers).
- Dalle-de-verre stained-glass bands (1.83 m) rising from the four compass
  points, folding over the arm tips into the ridge skylights of the cross.
  Each face carries its element — gold air (east), green earth (north), red
  fire (west), blue water (south) — meeting in a prismatic apex.
- 55 ft golden summit cross.
- A real interior: the nave opens straight up into the coffered cupola through
  the roof-deck annulus; Richard Lippold's baldacchino (tiers of emissive gold
  rods with the suspended crucifix) hangs over the Botticino sanctuary with
  altar, ambo and cathedra; pews flank processional aisles on three sides; the
  Ruffatti organ rises on its flaring pedestal.
- `BLENDER_PREVIEW_ONLY` carries a light rig (apex shaft, element fills, vault
  washes) so the .blend opens readable — none of it exports.

The in-game god rays are not baked into the GLB: `src/world/stMarys/index.ts`
is a disposable atmosphere layer (elemental beams, floor pools, the apex
column, dust motes) that attaches via `authoredRegions.watch("st-marys", ...)`
only while the region is resident, mirroring Grace Cathedral's layer.

Architectural references: <https://smcsf.org/a-sacred-space>,
<https://c20society.org.uk/building-of-the-month/cathedral-of-st-mary-of-the-assumption-san-francisco>,
Wikipedia (dimensions), and the north-east reference photograph used to match
the corner-edge taper (quarter-cosine profile in the generator).

Everything here — including the deterministic textures in `textures/` — is
regenerated by the create script. Editing the .blend directly is fine too; it
is the authority the bake exports from. To rebuild from scratch and publish:

```sh
npm run build:st-marys
```

or equivalently:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python tools/create-st-marys-site.py -- --repo "$PWD"
npm run bake:site -- --site st-marys
```

To re-publish after hand-editing the .blend in Blender (the normal loop):

```sh
npm run bake:site -- --site st-marys
```
