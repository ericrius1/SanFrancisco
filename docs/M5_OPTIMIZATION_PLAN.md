# M5 Air / WebGPU optimization review

Reviewed 2026-09-04. Target: the Apple M5 MacBook Air with 24 GB available in this workspace, plus other WebGPU-capable laptops and desktops. Full mobile support is outside this pass.

## Recommendation

The biggest next investment should be **less world work before and immediately after arrival**, followed by **fewer material compilations** and **less foliage pixel work**. Reducing polygon counts indiscriminately would miss the boot, streaming, and fragment costs already visible in this architecture.

Keep a single WebGPU renderer. Preserve the existing shared vegetation system, GPU indirect draws, temporal reconstruction, adaptive governor, worker-built road graph, prioritized arrivals, and bounded tree caches. These are useful foundations. Extend their ownership boundaries rather than introducing a second rendering or foliage stack.

This review includes an implemented first wave below. The larger architectural changes in the ranked plan remain proposed work; their performance benefit has not been measured or promised.

## Scope and evidence

The review followed the boot/composition graph, frame driver, render/post/compile pipeline, streaming and terrain ownership, physics scheduling, native trees and groundcover, vehicle/remote construction, audio, and existing musical sites. The source tree contains roughly 760 TypeScript modules and 233,000 lines. Principal entry points:

| Area | Files / findings |
| --- | --- |
| Boot and optional content | `src/main.ts`, `src/app/compose/{initialArrival,worldSystemsCore,worldSystemsNet,optionalSites}.ts`, `docs/LAZY_LOADING.md`. Many sites are correctly dynamic imports, but optional vehicle modules/prototypes and toy setup still enter the fundamental graph. |
| World residency | `src/world/tiles.ts`, `src/world/terrainTiles.ts`, `src/app/ringCoordinator.ts`, `src/config.ts`. Default draw distance is 18,000 m; the destination minimum and eventual world residency are separate policies. |
| Rendering | `src/app/frameDriver.ts`, `src/render/{pipeline,compileGate,adaptiveResolution,gpuIndirect}.ts`, `src/render/post/`. Compile windows can intentionally skip rendering while the application continues ticking. |
| Forests | `src/world/nativeTreeForest/`, `src/world/vegetation/`. Existing compiled-template cache is capped at 48; material and texture caches at 16 and 64. Preserve leases and shared ownership. |
| Grass / flowers | `src/world/groundcover/{foliageField,gpuGrassPlacement}.ts`, `src/world/wildlands/{grassField,flowerRing}.ts`, `src/world/garden/botanicalGrass.ts`. Placement is GPU-based, but culling was sized to maximum capacity and ecology publishes upload whole textures. |
| Vehicles / remotes | `src/player/player.ts`, `src/net/remotes.ts`, `src/world/traffic/`. Remote-player construction eagerly builds plane, boat, speedboat and drone prototypes. First-use vehicle splitting must cover both local and remote paths. |
| Existing art | Wave Organ, Fort Mason Ensemble, Palace Reverie, beach pianist and other optional sites provide the interaction, audio and streaming conventions for Tidal Choir. |

One production build emitted approximately 1.55 MB of minified main JavaScript (517 kB gzip), 1.07 MB of Three (298 kB gzip), and 1.12 MB of inline physics (356 kB gzip). These are individual chunk sizes, **not the complete boot transfer**. Large on-disk assets include city building/collider data and optional ML runtimes; disk size alone does not prove a boot request.

Existing `docs/PERF_LEVELUP.md` records invalid earlier measurements: missing manual node-frame advancement and subsequently contaminated comparisons. This review does not reuse those FPS claims. The new application probe records actual render-call advancement as well as rAF intervals. A 60 Hz rAF trace can accompany skipped render frames.

## Implemented in this worktree

1. **Population-sized groundcover culling.** A placement-finalization compute publishes indirect dispatch sizes from bounded live counts. Grass, botanical grass and all flower layers share the implementation. No per-frame CPU readback. Empty fields dispatch zero cull groups. Overflow clamps to arena capacity. Publication uses batches of seven destination buffers plus one live-count buffer, respecting the guaranteed eight-storage-buffer limit; the 11-layer flower case is tested.
2. **Skip unnecessary far-tree culls.** Empty designs leave the dispatch list. Unchanged camera/focus/residency reuses existing draw counts. Admission, retirement and near-pool handoffs invalidate the result; the final retirement clears and parks draws. Allocation `used` is deliberately not a high-water dispatch bound: fragmented live ranges can exist above it.
3. **Linear-time scheduler draining.** Replace repeated array-head removal with an amortized constant-time queue. Consumed job closures are released immediately; lane priority, positive-budget starvation protection and next-frame retries remain intact.
4. **Continuous quality pressure.** The adaptive governor now requires an uninterrupted hot/cool dwell. Neutral observations, pauses, warmup and re-enabling reset it. An isolated hitch after a long idle no longer inherits the entire idle duration as downscale pressure.
5. **Correct cancelled ecology paging.** A partial toroidal update can overwrite CPU slots belonging to the last published square. Reversing direction previously reused those stale samples. A replacement rebuild now repairs the square before publication. The regression test reproduced the old wrong height and passes with the fix. This correctness fallback intentionally resamples on cancellation; normal completed movement still uses slabs.
6. **Tidal Choir, Marin.** Six walk-on colored chimes form a shared chord around a kinetic spiral. Existing replicated walking positions supply participation; multiple people on one pad do not multiply its gain. The existing relay snapshot clock synchronizes musical pulses. Sound uses the shared music bus and procedural oscillators. Two lightweight visitors circulate outside the pads. Shared cypress and flower patches stream independently of the gameplay site, with a grass-free playable clearing.
7. **Optional volumetric clouds.** A bounded WGSL ray march shades the existing sky draw, with sun-facing lighting, coverage/base controls, early exits, and fewer steps at economy governor levels. The shader is a first-use chunk; no textures, new full-screen pass, or extra target. Disabled by default; enable under `/` → lighting → volumetric clouds, or `?clouds=1`. This is a sky volume, not a complete weather simulation: it does not cast terrain shadows or attenuate every object inside the cloud layer.
8. **Bounded ambient street life.** Up to 18 cars across three instanced model draws and 12 shared avatar rigs, with 10 Hz simulation, bounded road queries, signal stops, lane spacing and distance recycling. Economy governor levels reduce the population to nine cars / six walkers. Walking or driving 12 m activates the first-use gate near a road; `?citylife=1` explicitly opts in for review. These are ambient vehicles, not enterable vehicles or a replacement for the driving controller. Junction routing remains a future improvement; cars currently finish local segments and recycle out of the immediate view.

9. **Pocket residency stays bounded until wake.** Zone mode now caps baked-tile residency and terrain-data requests independently of the draw-distance slider. Startup restore, stall recovery and factory reset respect the zone radius; “Wake the city” explicitly lifts both caps. Full-world residency behavior is preserved. The scan/morph animation uses the same smaller boundary instead of waiting for the 45-second terrain timeout. In the final Marin pocket trace, 17 terrain tiles and eight baked tile entries loaded, compared with 342 and 417 before the boundary fix. These are workload counts, not total memory or FPS percentages.

The main checkout's pre-existing local performance changes were preserved in the isolated baseline commit `b1cf10f`; they are not counted as new work in this list.

## Device and measurement contract

Initial **targets**, not measured guarantees:

| Profile | Intended use | Initial acceptance target |
| --- | --- | --- |
| Balanced | M5 Air class, plugged in or normal battery use | 60 Hz target at a fixed 1512×982 CSS viewport, explicitly recorded output/internal scale. Warm-route p95 submitted-frame interval ≤20 ms; streaming p99 ≤50 ms with stalls attributed. Clouds stay opt-in until their overhead is measured. |
| Quiet | Fanless/battery or smaller integrated GPU | Sustained 30 Hz, p95 ≤36 ms, bounded population/foliage, no repeating resolution changes. Evaluate after 20 minutes, not only a cold launch. |
| High | More GPU and thermal headroom | Higher internal scale and cloud detail only while measured headroom remains. Preserve the same streaming and first-use boundaries. |

Use Golden Gate approach, downtown walking/driving, Japanese Tea Garden, Marin redwoods, Tidal Choir, a shoreline, and a heavy interior. Run cold boot, warm stationary view, a repeatable moving route, rapid teleport/reversal, two-client interaction, and a 20-minute thermal soak. Record browser/adapter/OS, CSS and drawing-buffer size, internal scale, governor state, power mode, actual render intervals, GPU timings if available, compile-held frames, scheduler backlog, transfer bytes and renderer memory. Test a WebGPU-capable Windows integrated GPU and Safari separately before claiming cross-device coverage; those runs are not completed here.

Treat renderer memory as an attributed resource estimate, not total process or unified-memory consumption. Set profile memory budgets from repeated-route plateaus and available headroom; a one-time low memory sample is insufficient.

## Validation from this pass

- CPU contracts pass: 12,000-job FIFO/lane draining, next-frame retries, zero-budget behavior, quality dwell, camera/focus invalidation, far-tree admission/retirement/near handoff, pad hit tests, cancelled toroidal paging, and pocket scan completion without the terrain timeout.
- Real headless WebGPU tests pass for empty, sparse, dense and overflowing grass populations. Indirect and capacity culls return identical visible counts. The sparse fixture uses **19 workgroups versus 483**, a 96.1% dispatch-group reduction. This is a controlled compute fixture, **not a 96.1% game speedup**. Eleven flower layers publish in two legal batches without validation errors.
- Real browser feature QA passes: zero new optional feature code at clean boot; cloud shader on activation and no new cloud assets for coverage changes; clear-sky restoration; two connected clients contributing different choir pads; one voice when sharing a pad; departure and gameplay/vegetation unload; “Wake the city” lifting the cap; ordinary walking activating 18 ambient cars / 12 walkers / three car draws. No browser errors in that run.
- Scene-light budget, ambient-bird removal, foliage-shadow, terrain-tile, city-tile-grounding, building-facade, post-chain, audio-context, native-tree LOD-transition and vegetation-wind contracts pass. The existing grounding check notes one tile's pre-existing per-building discrepancy.
- TypeScript and standalone Vite production bundling pass. Clouds, ambient city life, Tidal Choir gameplay, and its vegetation are separate production chunks.
- The normal asset gate remains red for pre-existing Fort Mason, Grace Cathedral, St Mary's Cathedral and Sutro Baths source/output ledger mismatches. This pass does not rewrite that ledger or silently rebake the architecture.
- The final Marin pocket smoke probe passes with clouds enabled, a 900 m residency cap, no GPU errors and no scan-age timeout. It observed 229 render-advancing refreshes out of 241 sampled refreshes; p95 render-advancing interval was 33.3 ms. That remains short of the Balanced target. Earlier runs failed the render-advancement gate. A controlled whole-world before/after FPS comparison and thermal measurements are **not certified** and remain the first plan item.

Reproducible tools: `tools/world-upgrade-contract-test.mjs`, `tools/world-upgrade-gpu-probe.mjs`, `tools/world-upgrade-features-probe.mjs`, and `tools/world-upgrade-probe.mjs`. Browser artifacts are under `.data/world-upgrade/`. Set `SF_PROBE_URL` when using a port other than 5270.
